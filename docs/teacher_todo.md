# Teacher 模式改进清单

把当前残差+模仿方案的薄弱点和对应的“怎么做、看什么”列出来，便于对症下药。

## 待改进点

- [ ] **一上来就崩（残差要扛质量/惯量差）**  
  - 怎么做：先来一轮“扶上马”——高权重模仿/BC 预热（`imitation_weight` 大、`dagger_frac` 接近 1，低 entropy），或开局让基控制临时同步质量，稳定后再切回名义惯量。
  - 看什么：前 5e4 步内，episode length > 80% 上限，`imitation/err` < 0.2。

- [ ] **专家混合死板，误差不下去**  
  - 怎么做：让 `dagger_frac` 逐步下降（如 0.8→0.5→0），同时降低 `imitation_weight`，必要时插入短的纯 BC 轮次。
  - 看什么：`imitation/err` 随阶段降低到 <0.3，episode 没出现大掉崖。

- [ ] **噪声大/撞限多，bounds_loss 飙升**  
  - 怎么做：再收紧 lr/e_clip/kl，调低 `entropy_coef`，监控 bounds；必要时放宽补偿限幅或减小补偿惩罚。
  - 看什么：clip_frac ~0.1，bounds_loss < 5，entropy 不持续上扬。

- [ ] **特权信息“瞎填”或无效**  
  - 怎么做：保留可训练编码器，梳理特权字段，去掉恒值/未随机化项，优先补齐动力/混控/扰动相关的真值。
  - 看什么：去冗余后收敛不变或更好；编码器梯度非零（模型侧可监控）。

- [ ] **难度上来太快，episode 卡低**  
  - 怎么做：先降难度（短 episode/低扰动/少载荷）做 curriculum，策略稳了再恢复全难度。
  - 看什么：低难度时 episode 接近上限，恢复后没有明显崩。
